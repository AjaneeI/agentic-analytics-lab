# Blocker Definition Policy

## Blocked item
A blocked item is active work that cannot make material progress because a required dependency, approval, or decision is unavailable. Time waiting alone does not make an item blocked.

## Blocker rate
Blocker rate is the count of blocked active items divided by all active items in the selected scope. The numerator and denominator must use the same scope and snapshot.

## Dependency ownership
Every blocked item should name the dependency owner and the next evidence-producing action when those facts are known.
