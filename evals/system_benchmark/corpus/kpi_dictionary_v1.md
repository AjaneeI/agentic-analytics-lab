# KPI Dictionary

## Blocker rate
Blocker rate is the count of blocked active work items divided by all active work items in the selected scope. Report the value as a percentage and identify the scope used.

## Aging work
Aging work is active work whose age exceeds the reporting window defined for the team. Aging work and blocker rate are related operational signals but are not interchangeable.

## Effort ratio
Effort ratio compares actual effort to planned effort for the same work population. It is not a causal measure of delivery delay.
