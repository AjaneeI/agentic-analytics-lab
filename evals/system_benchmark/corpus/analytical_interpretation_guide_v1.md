# Analytical Interpretation Guide

## Association and causality
An observed association between blocker rate and delivery outcome does not establish that blockers caused the outcome. A causal claim requires a design or evidence source that supports causal inference.

## Scope alignment
Comparisons must use compatible populations, time windows, and metric definitions. If scopes differ materially, state the mismatch instead of combining the values.

## Unsupported evidence
If a requested source is unavailable to the system, do not fabricate access, citations, or measurements. State the missing evidence and the bounded conclusion that remains supportable.
